# Quran Audio Packages

Public download packages used by the Azkar app. The source application repository remains private.

Available packages:

- `mishary/quran.zip` — Mishary Rashid Alafasy, 114 surahs.
- `hani/quran.zip` — Hani Al Rifai, 114 surahs.
- `albanna/quran.zip` — Mahmoud Ali Al Banna, 114 surahs.
- `yasser/quran.zip` — Yasser Al-Dossari, 114 surahs.

All packages are normalized as `quran/001.mp3` through `quran/114.mp3`. The Hani and Al Banna source archives were stored in reverse order; they were corrected using the embedded MP3 title metadata before publication.
